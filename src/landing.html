A remote MCP server with no authentication. Every template comes with a description of what it means and what each line is for, so your agent picks the right one.

Endpoint{{BASE_URL}}/mcp

Run this once, then ask Claude for a meme.

claude mcp add --transport http memegen {{BASE_URL}}/mcp

Open Settings → Connectors, choose Add custom connector, and paste the endpoint. Memes then show up in an interactive view right in the chat.

{{BASE_URL}}/mcp

Add this to ~/.cursor/mcp.json.

{
  "mcpServers": {
    "memegen": { "url": "{{BASE_URL}}/mcp" }
  }
}

Add the server from your terminal.

code --add-mcp '{"name":"memegen","type":"http","url":"{{BASE_URL}}/mcp"}'

Build the binary and run it over stdio. Memes are saved to a local cache, and a new one takes about half a millisecond.

# in a clone of github.com/edenstrom/memegen-rust
cargo build --release
claude mcp add memegen -- "$PWD/target/release/memegen" mcp
